# CampusFest – College Event Management Website

A responsive website where students can browse college events and register for them. Built as the Web Essentials 2nd Assignment mini project.

**Live demo:** https://S-Atchayakumaran0701.github.io/college-event-management/

## Features

- Responsive layout that works on mobile, tablet and desktop
- Event cards with date, category, venue and description
- Search events by name or venue
- Filter events by category (Technical, Cultural, Sports, Workshop)
- Registration form with validation (name, email, department, event)
- Duplicate registration check
- My registrations list with a cancel option
- Registrations saved in the browser using localStorage

## Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, media queries)
- JavaScript (DOM manipulation, localStorage)

## How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.

No installation or server is needed.
